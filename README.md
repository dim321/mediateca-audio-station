# mediateca-audio-station

Go-агент аудио-станции для Linux mini-PC. Забирает у Hub суточный таймлайн, кэширует файлы и играет их локальным `mpv` на один псевдоэкран.

Реализация ещё не начата. Спека и план:

- `mediateca-broadcast/docs/superpowers/specs/2026-10-20-audio-station-agent-design.md`
- `mediateca-broadcast/docs/superpowers/plans/2026-10-20-audio-station-agent.md`

Прототип на Ruby/Spinel, который не собирается в бинарь, лежит в `mediateca-audio-station-ruby`.
